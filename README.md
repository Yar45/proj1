# Развертывание Docker и 3x-ui на Ubuntu

В данном каталоге находятся два скрипта для быстрой и безопасной установки Docker и панели управления **3x-ui** на чистый сервер с ОС Ubuntu.

* `docker-install.sh` — автоматическая установка Docker Engine, CLI, Containerd и Docker Compose Plugin из официального репозитория Docker.
* `3x-ui-install.sh` — настройка фаервола (UFW), получение SSL-сертификата Let's Encrypt, запуск 3x-ui через Docker Compose и первоначальная настройка учетных данных (логин, пароль, порт, URL-путь).

---

## 1. Скачивание скриптов с GitHub на сервер Ubuntu

Подключитесь к вашему серверу по SSH:
```bash
ssh root@<IP_СЕРВЕРА>
```

Выберите один из вариантов скачивания:

### Вариант 1: Клонирование репозитория через Git (Рекомендуется)

Установите `git` (если он не установлен), клонируйте проект и перейдите в папку:

```bash
sudo apt update && sudo apt install -y git
git clone https://github.com/ВАШ_ЛОГИН_GITHUB/ВАШ_РЕПОЗИТОРИЙ.git
cd ВАШ_РЕПОЗИТОРИЙ
```

> **Для приватного репозитория:**
> Если ваш репозиторий приватный, укажите токен доступа (Personal Access Token):
> ```bash
> git clone https://<ВАШ_GITHUB_ТОКЕН>@github.com/ВАШ_ЛОГИН_GITHUB/ВАШ_РЕПОЗИТОРИЙ.git
> ```

---

### Вариант 2: Прямое скачивание скриптов через `curl` (без клонирования Git)

Если репозиторий публичный, можно скачать только необходимые скрипты в отдельную папку:

```bash
mkdir -p ~/x-ui-install && cd ~/x-ui-install

# Скачать docker-install.sh
curl -fsSL https://raw.githubusercontent.com/ВАШ_ЛОГИН_GITHUB/ВАШ_РЕПОЗИТОРИЙ/main/docker-install.sh -o docker-install.sh

# Скачать 3x-ui-install.sh
curl -fsSL https://raw.githubusercontent.com/ВАШ_ЛОГИН_GITHUB/ВАШ_РЕПОЗИТОРИЙ/main/3x-ui-install.sh -o 3x-ui-install.sh
```

---

## 2. Пошаговый запуск скриптов

### Шаг 1. Сделайте скрипты исполняемыми

В папке со скачанными скриптами выполните:

```bash
chmod +x docker-install.sh 3x-ui-install.sh
```

---

### Шаг 2. Установка Docker

Запустите скрипт установки Docker:

```bash
sudo ./docker-install.sh
```

*(Опционально)* Чтобы управлять Docker без `sudo`:
```bash
sudo usermod -aG docker $USER
newgrp docker
```

Проверить корректность установки:
```bash
docker --version
docker compose version
```

---

### Шаг 3. Установка и настройка 3x-ui

Запустите скрипт одним из способов:

#### Способ А: Интерактивный запуск (рекомендуется)
Скрипт пошагово запросит все необходимые параметры:
1. IP-адрес сервера (вручную).
2. Домен (опционально, для SSL).
3. E-mail (обязателен при указании домена).
4. Порт панели (по умолчанию `2053`).
5. Логин (по умолчанию `admin`).
6. Пароль (предложит сгенерированный или ваш).
7. URL-путь (по умолчанию `/`).

```bash
sudo ./3x-ui-install.sh
```

#### Способ Б: Передача IP и домена аргументами
Можно сразу передать IP сервера (и домен) при запуске:

```bash
# Передать только IP:
sudo ./3x-ui-install.sh 194.87.12.34

# Передать IP и домен:
sudo ./3x-ui-install.sh 194.87.12.34 example.com
```

## 3. После установки

После завершения работы скрипта в консоль будет выведена итоговая сводка:

```text
==========================================================
          3x-ui успешно настроен и запущен!               
==========================================================
Панель управления доступна по адресам:
  http://<IP_СЕРВЕРА>:<ПОРТ>/<URL_ПУТЬ>
  (или https://<ДОМЕН>:<ПОРТ>/<URL_ПУТЬ> после включения SSL в настройках)

Параметры авторизации:
  Логин:       <ВАШ_ЛОГИН>
  Пароль:      <ВАШ_ПАРОЛЬ>
  Порт панели: <ВАШ_ПОРТ>
  URL-путь:    <ВАШ_ПУТЬ>
==========================================================
```

### Полезные команды управления контейнером:

```bash
# Проверить статус контейнера
docker ps

# Посмотреть логи работы 3x-ui в реальном времени
docker logs -f 3x-ui

# Перезапустить контейнер панели
docker restart 3x-ui

# Полная остановка / перезапуск через Docker Compose
cd /opt/3x-ui
docker compose down
docker compose up -d
```
