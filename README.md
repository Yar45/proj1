# Развертывание Docker и 3x-ui на Ubuntu

В данном каталоге находятся два скрипта для быстрой и безопасной установки Docker и панели управления **3x-ui** на чистый сервер с ОС Ubuntu.

---

## Файлы проекта

* `docker-install.sh` — скрипт автоматической установки Docker Engine, Docker CLI, Containerd и Docker Compose Plugin из официального репозитория Docker.
* `3x-ui-install.sh` — скрипт настройки фаервола (UFW), получения бесплатного SSL-сертификата Let's Encrypt (опционально), запуска 3x-ui через Docker Compose и первоначальной настройки учетных данных (логин, пароль, порт, URL-путь).

---

## Пошаговая инструкция по запуску

### Шаг 1. Сделайте скрипты исполняемыми

Выполните команду в папке со скриптами:

```bash
chmod +x docker-install.sh 3x-ui-install.sh
```

---

### Шаг 2. Установка Docker

Запустите первый скрипт:

```bash
sudo ./docker-install.sh
```

*(Опционально)* Если вы хотите управлять Docker без постоянного ввода `sudo`:
```bash
sudo usermod -aG docker $USER
newgrp docker
```

Проверить корректность установки:
```bash
docker --version
docker compose version
```

---

### Шаг 3. Установка и запуск 3x-ui

Запустите второй скрипт одним из удобных способов:

#### Вариант А: Интерактивный режим (рекомендуется)
Скрипт пошагово запросит все параметры (IP-адрес, домен, email, порт, логин, пароль и URL-путь):

```bash
sudo ./3x-ui-install.sh
```

#### Вариант Б: С передачей параметров в командной строке
Вы можете сразу передать IP сервера и домен позиционными аргументами:

```bash
# Передать только IP:
sudo ./3x-ui-install.sh 194.87.12.34

# Передать IP и домен:
sudo ./3x-ui-install.sh 194.87.12.34 example.com
```

---

## После установки

После завершения работы скрипта вы увидите итоговую сводку с готовыми ссылками для перехода в браузер, а также сохраненные данные авторизации:

```text
Панель управления доступна по адресам:
  http://<IP_СЕРВЕРА>:<ПОРТ>/<URL_ПУТЬ>
  (или https://<ДОМЕН>:<ПОРТ>/<URL_ПУТЬ> после включения SSL в настройках)

Параметры авторизации:
  Логин:       <ВАШ_ЛОГИН>
  Пароль:      <ВАШ_ПАРОЛЬ>
  Порт панели: <ВАШ_ПОРТ>
  URL-путь:    <ВАШ_ПУТЬ>
```

### Полезные команды управления контейнером:

```bash
# Проверить статус контейнера
docker ps

# Посмотреть логи 3x-ui
docker logs -f 3x-ui

# Перезапустить панель
docker restart 3x-ui

# Остановить / Запустить через compose
cd /opt/3x-ui
docker compose down
docker compose up -d
```
