# Xray VPN: Двухузловой каскад с Self-Steal SNI, XHTTP и защитой от блокировок

Данная архитектура построена на базе актуальных рекомендаций и анализа работы ТСПУ/РКН (ноябрь 2026 года). Она решает обе главные проблемы современных блокировок:
1. **Защита от блокировки по IP:** Входной IP сервера изолирован от выходного IP в интернет. Российские приложения видят белый российский IP, а зарубежные сервисы видят выходной зарубежный IPv4. Входной зарубежный IPv6 скрыт от внешнего мира.
2. **Защита от DPI и заморозки трафика:** Используется связка **VLESS + REALITY + XHTTP (SplitHTTP)**. Никакого сырого TCP (который замораживается через 16 КБ) и никакого чужого ворованного SNI (Stolen SNI). На серверах работает полноценная маскировка под собственный легитимный веб-сайт (**Self-Steal SNI**).
3. **Безопасность портов («Всё на 443 порту»):** Наружу открыт **только порт 443**. Веб-сайт, VPN-туннель, сервер подписок и секретная админ-панель работают на одном порту без подозрительных открытых сервисов.

## 🏛 Схема движения трафика

```text
                                  [ Пользователи: Смартфоны / ПК ]
                                   │                           │
                   (Скачивание подписки)                       │ (VPN-трафик: VLESS + REALITY + XHTTP)
                                   ▼                           ▼
                     [ Yandex API Gateway ]             [ Сервер в РФ ]
               (Белый список, "вечная ссылка")       (ru.example.com : 443)
                                   │                           │
                                   │                           ├──► [RU Трафик] ──► Банки, Госуслуги, .RU
                                   ▼                           │    (Direct через российский IPv4)
                           [ Сервер подписок ]                 │
                          (Локально в Nginx)                   ▼ (Туннель по IPv6: VLESS + REALITY + XHTTP)
                                                        [ Сервер за рубежом ]
                                                     (eu.example.com, только AAAA)
                                                               │
                                                               ▼ (Выход в мир через IPv4)
                                                     [ Зарубежный Интернет ]
                                                     (YouTube, Instagram, ChatGPT...)
```

## Шаг 1. Настройка DNS (например, в Cloudflare)

Зайдите в управление DNS для вашего домена (например, `example.com`) и создайте две записи:

1. **`ru.example.com`** (Сервер в РФ):
   * **Тип:** `A`
   * **IPv4 адрес:** внешний IPv4 адрес вашего сервера в РФ
   * **Proxy status:** **DNS Only (серое облако!)**
   * **TTL:** `Auto` или `1 min`
2. **`eu.example.com`** (Зарубежный сервер):
   * **Тип:** `AAAA`
   * **IPv6 адрес:** внешний IPv6 адрес вашего зарубежного сервера
   * **Proxy status:** **DNS Only (серое облако!)**
   * **TTL:** `Auto` или `1 min`
   * *(Запись типа A с IPv4 адресом зарубежного сервера намеренно НЕ создается, чтобы этот IP не светился в DNS).*

## Шаг 2. Развертывание зарубежного сервера (EU — `eu.example.com`)

> **ВАЖНО:** Зарубежный сервер настраивается **первым**, так как его ключи понадобятся для настройки сервера в РФ.

1. Подключитесь по SSH к **зарубежному серверу**:
   ```bash
   ssh root@<IPv4_ИЛИ_IPv6_EU_СЕРВЕРА>
   ```
2. Установите Docker:
   ```bash
   chmod +x docker-install.sh && sudo ./docker-install.sh
   ```
3. Запустите установку 3x-ui:
   ```bash
   chmod +x 3x-ui-install.sh && sudo ./3x-ui-install.sh
   ```
   * При запросе роли выберите: **`2` (Зарубежный выходной шлюз)**.
   * Домен: введите ваш субдомен (например, `eu.example.com`).
   * Введите ваш e-mail для Let's Encrypt.
   * Задайте или сгенерируйте пароль и секретный 16-значный путь панели (сохраните их!).

4. **Настройка в панели 3x-ui (EU):**
   * Откройте выданную ссылку: `https://eu.example.com/секретный-путь/`
   * Перейдите в **«Подключения» (Inbounds)** ➔ **«Добавить подключение»**:
     * **Протокол:** `vless`
     * **Порт:** `443`
     * **Сеть (Transmission):** `xhttp`
     * **Flow:** строго **None (пусто!)**
     * **Безопасность:** `Reality`
     * **uTLS:** `firefox`
     * **Dest (Target):** `127.0.0.1:8080` *(наш локальный Nginx)*
     * **Server Names (SNI):** `eu.example.com`
     * Нажмите кнопку **«Сгенерировать»** ключи и ShortId.
     * Сохраните инбаунд.
   * Перейдите в **«Настройки Xray» (Xray Setting)** ➔ **«Исходящие» (Outbounds)**:
     * Найдите правило с тегом `direct` (протокол `freedom`).
     * В поле **Domain Strategy** выберите: `UseIPv4` *(чтобы все запросы в мир выходили строго через IPv4)*.
     * Нажмите «Сохранить конфигурацию» и «Перезапустить ядро».
   * **Скопируйте параметры клиента:** перейдите в список Inbounds, нажмите на иконку QR-кода/информации у добавленного подключения и скопируйте:
     * **Public Key (pbk)**
     * **ShortId (sid)**
     * **UUID клиента**

## Шаг 3. Развертывание сервера в РФ (RU — `ru.example.com`)

1. Подключитесь по SSH к **российскому серверу**:
   ```bash
   ssh root@<IPv4_RU_СЕРВЕРА>
   ```
2. Установите Docker:
   ```bash
   chmod +x docker-install.sh && sudo ./docker-install.sh
   ```
3. Запустите установку 3x-ui:
   ```bash
   chmod +x 3x-ui-install.sh && sudo ./3x-ui-install.sh
   ```
   * При запросе роли выберите: **`1` (Российский входной узел)**.
   * Домен: введите ваш субдомен (например, `ru.example.com`).
   * Введите ваш e-mail для Let's Encrypt.
   * Задайте или сгенерируйте пароль и секретный путь панели.

4. **Настройка в панели 3x-ui (RU):**
   * Откройте выданную ссылку: `https://ru.example.com/секретный-путь/`

   * **А. Добавление туннеля на EU-сервер:**
     * Перейдите в **«Настройки Xray»** ➔ **«Исходящие» (Outbounds)** ➔ **«Добавить исходящее»**:
       * **Протокол:** `vless`
       * **Тег (Tag):** `tunnel-to-eu`
       * **Адрес (Host):** `eu.example.com` *(или скопированный IPv6 адрес EU-сервера)*
       * **Порт:** `443`
       * **UUID:** вставьте UUID из EU-панели
       * **Сеть (Transmission):** `xhttp`
       * **Безопасность:** `Reality`
       * **SNI:** `eu.example.com`
       * **Public Key:** вставьте Public Key из EU-панели
       * **ShortId:** вставьте ShortId из EU-панели
       * **Fingerprint:** `firefox`

   * **Б. Настройка разделения трафика (Routing Rules):**
     * Перейдите во вкладку **«Правила маршрутизации» (Routing Rules)**:
       * **Правило 1 (Российские сервисы):**
         * Outbound Tag: `direct`
         * Domains: `geosite:category-ru`
         * IP: `geoip:ru`
       * **Правило 2 (Заблокированные и зарубежные сайты):**
         * Outbound Tag: `tunnel-to-eu`
         * Domains: `geosite:blocked`, `geosite:geolocation-!cn`
       * **Правило по умолчанию (Default):** направлять в `tunnel-to-eu`.
     * Нажмите «Сохранить конфигурацию» и «Перезапустить ядро».

   * **В. Добавление подключения для клиентов (смартфоны, ПК):**
     * Перейдите в **«Подключения» (Inbounds)** ➔ **«Добавить подключение»**:
       * **Протокол:** `vless`
       * **Порт:** `443`
       * **Сеть (Transmission):** `xhttp`
       * **Flow:** строго **None (пусто!)**
       * **Безопасность:** `Reality`
       * **uTLS:** `firefox`
       * **Dest:** `127.0.0.1:8080`
       * **Server Names (SNI):** `ru.example.com`
       * Нажмите «Сгенерировать» ключи и сохраните.

## Шаг 4. Настройка неубиваемых подписок через Yandex API Gateway

Чтобы клиенты могли получать обновления подписки даже во время жестких «белых списков» и блокировок:

1. Зайдите в консоль [Yandex Cloud](https://console.cloud.yandex.ru/) (действует Free Tier: 1 млн запросов в месяц бесплатно).
2. Перейдите в раздел **API Gateway** ➔ нажмите **«Создать шлюз»**.
3. Введите любое имя (например `app-sync`) и вставьте в окно спецификации OpenAPI код:

```yaml
openapi: 3.0.0
info:
  title: sync-service
  version: 1.0.0
paths:
  /sub/{proxy+}:
    get:
      x-yc-apigateway-integration:
        type: http
        url: https://ru.example.com/sub/{proxy}
```

4. Нажмите **«Создать»**. Яндекс выдаст вам адрес шлюза вида:  
   `https://d5d123456789abcdef.apigw.yandexcloud.net`

5. **Итоговая ссылка на подписку для пользователей:**
   ```text
   https://d5d123456789abcdef.apigw.yandexcloud.net/sub/<ТОКЕН_КЛИЕНТА_ИЗ_3X_UI>
   ```

## Шаг 5. Настройка приложений на устройствах

Вставьте ссылку на подписку в клиентское приложение:
* **Android:** [NekoBox](https://github.com/MatsuriDayo/NekoBoxForAndroid), v2rayNG, Sing-box, Happ.
* **iOS:** Happ, Streisand, Shadowrocket, Sing-box.
* **Windows:** [v2rayN](https://github.com/2dust/v2rayN), NekoBox for Windows.

### Рекомендуемые настройки в приложении:
1. **Sniffing (Сниффинг доменов):** Включен (ON). Позволяет ядру сервера читать запрашиваемые имена сайтов внутри TUN-режима.
2. **DNS (DoH):** `https://1.1.1.1/dns-query` или `https://77.88.8.8/dns-query`.
3. **IPv6:** Выключить IPv6 внутри клиентского туннеля (Drop AAAA), чтобы исключить утечки оператора.

## 🔒 Безопасность и сопровождение

* **Порты на серверах:** Открыты только порты `22`, `80` и `443`.
* **Сертификаты Let's Encrypt:** Обновляются автоматически по крону Certbot без остановки веб-сервера.
* **Панель управления:** Доступна только вам по защищенному адресу `https://<домен>/<секретный_16_значный_путь>/`.
* Если кто-то открывает корень сайта `https://ru.example.com/` в обычном браузере — он видит легитимную веб-страницу заглушки с SSL-сертификатом Let's Encrypt.
* **Управление контейнерами (3x-ui + Nginx):**
  ```bash
  cd /opt/vpn && docker compose ps        # Статус контейнеров
  cd /opt/vpn && docker compose logs -f   # Просмотр логов в реальном времени
  cd /opt/vpn && docker compose restart   # Перезапуск стека
  ```
